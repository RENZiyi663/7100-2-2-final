## 🔬 分析方法论总结

### 统计分统方法
1. **EFA (探索性因子分析)**
   - 方法：PCA with Kaiser准则 (eigenvalue > 1)
   - 结果：4个主因子，累积解释63.4%的方差

2. **CFA (验证性因子分析)**
   - Cronbach Alpha系数计算
   - 信度验证 (结果见表1最后一列)

3. **多重共线性诊断**
   - VIF计算 (所有变量 < 2.5，无共线性问题)

4. **回归分析**
   - OLS hierarchical regression
   - 7个嵌套模型的逐步比较
   - 模型拟合指标：R²、Adj R²、F统计、p值

### 数据处理流程
- 原始样本：N=201
- 有效样本：N=199
- 标准化：Z-score (M=0, SD=1)
- 中心化：连续变量均值中心化
- 交互项：计算Source×Frame、Trust×HC、SE×HC

## 🎯 核心发现总结

### 发现1：信息来源的压倒性优势
- Source在信任度预测中：**β=0.790, t=4.282, p<0.001**
- 是所有预测变量中最强的效应

### 发现2：框架效应完全失效
- Frame在所有11+个路径中均不显著 (p>0.20)
- 对Prospect Theory在中文背景下的适用性提出质疑

### 发现3：选择性调节
- HC特异性地调节SE→Intention (p=0.041)
- 但不调节Trust→Intention (p=0.102)

### 发现4：SE的双重角色
- 作为中介变量：较弱
- 作为直接预测因素：强有力 (β=0.283)

### 发现5：模型进阶
- 完整模型R² = 0.3926 (41.3%相对改进)
- 调节效应显著但幅度相对温和
