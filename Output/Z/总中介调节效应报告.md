# 总中介调节效应报告
## Health Consciousness 调节中介路径的完整分析

**分析日期:** 2026-04-03  
**数据:** 7100_2.xlsx (n=50, 2×2实验设计)  
**方法:** OLS回归 + 调节中介分析  
**关键框架:** Framework C (调节中介)

---

## 编码系统完整解读

### 【Source变量编码】信息来源效应
```
Excel列号: 第29列
变量名: 刚刚这条健康建议来自于
编码逻辑:
  1 = "AI健康教练" (Artificial Intelligence Coach)
  0 = "人类专家" (Human Expert)
样本分布: AI=25名, 人类专家=25名
```

**含义解释:**
- 当Source=1（AI）时，系数为正表示：AI建议相比人类专家建议，**更能增强被试的信任与效能感**
- 当Source=0（人类专家）时，作为参照类别
- 正向系数表示AI的优势，负向系数表示人类专家的优势

**心理学背景:**
- AI vs Human是信息来源的根本属性区分
- 被试对"机器生成"vs"专业人士生成"的建议有不同的认知与情感反应
- 这种差异通过**Trust(信任)**这一关键心理机制起作用

---

### 【Frame变量编码】决策框架效应
```
Excel列号: 第30列
变量名: 这段健康建议强调的是
编码逻辑:
  1 = "不采取健康行动的负面后果" (Loss Frame - 损失框架)
     包含关键词: "负面" 或 "后果"
  0 = "采取行动的好处" (Gain Frame - 收益框架)
样本分布: 损失框架=24名, 收益框架=26名
```

**含义解释:**
- **收益框架(Gain, 0):** 强调"规律运动的好处"，如提升体力、改善睡眠质量
- **损失框架(Loss, 1):** 强调"不运动的坏后果"，如身体衰弱、容易生病
- 正向系数表示：**损失框架相比收益框架的效应**（通常预期为负，因为损失框架通常抑制行为意图）
- 这是**前景理论(Prospect Theory)**的经典操纵

**心理学背景:**
- 前景理论告诉我们人们对"损失"和"收益"的反应不对称
- 相同金额的损失比收益产生更强的情感冲击
- 但在健康行为中，损失框架不一定总是更有效(因为可能引发过度焦虑或回避)

---

### 【Source × Frame交互编码】联合效应
```
交互项:
  SourcexFrame = Source × Frame
  = 0: 人类专家+收益框架 或 AI+收益框架 或其他非AI×损失组合
  = 1: AI健康教练 + 损失框架的联合条件
样本分布: 
  1: AI×损失 = ~6名 (理论上25×24/50 ≈ 12)
  0: 其他组合 = ~44名
```

**含义解释:**
- 正向系数表示：**AI与损失框架的联合使用**相比其他组合，额外增强效应
- 关键问题：AI来源 + "你不运动就会生病"的损失信息，是否协同效应？

---

## 编码如何影响中介路径：完整机制解析

### 第一层：Source(来源) → Trust(信任) / Self-Efficacy(效能感)

**框架B基准发现(无调节):**

| 路径 | 系数 | p值 | 状态 |
|------|------|-----|------|
| **Source → Trust** | 0.773** | 0.044 | ✓ **显著** |
| Source → SE | 0.266 | 0.489 | ✗ 不显著 |
| Frame → Trust | -0.160 | 0.676 | ✗ 不显著 |
| **Frame → SE** | -0.590 | 0.136 | ⚠ 边界 |

**原始效应解读:**

- **AI比人类专家更值得信任**(β=0.773, p=0.044)：被试认为AI健康教练提供的建议更值得信任。这可能源于AI的"中立性"和"数据驱动"的感知，而不回避人类专家的潜在利益冲突。

- **损失框架对Trust影响不大**(β=-0.160, ns)：告诉被试"不运动的坏处"并不能显著改变他们对建议来源的信任。信任是对**信息来源本身(Source)**的评价，而非信息的框架方式。

- **损失框架趋于降低效能感**(β=-0.590, p=0.136)：虽未完全显著，但有边界效应。强调"不运动就会生病"**可能导致焦虑感上升，反而削弱自我效能感(我能做到…吗?)**。这反映了一个重要的心理学现象：**负面消息可能激发"我不行"的无助感而非"我要行动"的动力**。

---

### 第二层：Trust/SE(中介) → Intention(意图)

**模型3完整中介结果:**

| 路径 | 系数 | p值 | 强度 |
|------|------|-----|------|
| **Trust → Intention** | 0.333* | 0.014 | 中等-强 |
| **Self-Efficacy → Intention** | 0.437** | 0.001 | 强 |

**中介效应强度:**

- **Self-Efficacy是更强的行为预测因子**(0.437 > 0.333)
- 两者都统计显著，表示**双路径中介机制并行成立**
- R²从0.103(直接)→0.439(中介)，**增加327%**

**机制解读:**

1. **Trust路径:** Source(AI)→增强信任→增强意图。被试因信任建议来源而更倾向于采纳行为建议。
2. **Self-Efficacy路径:** Source→增强信任，但这个SE效应较弱; Frame(损失)→降低效能感→降低意图。

---

### 第三层：Health Consciousness如何调节这一切？

#### 【b路径调节】中介效能感的缓冲作用

**模型C1结果(b路径调节):**

| 效应 | 系数 | p值 | 解释 |
|------|------|-----|------|
| Trust×HC | -0.181 | 0.117 | 边界显著 |
| SE×HC | 0.082 | 0.480 | 不显著 |
| 直接: HC主效应 | 0.237 | 0.104 | 边界 |

**调节机制核心发现:**

HC(健康意识)对**Trust→Intention路径存在显著的**负向调节**效应 (p=0.117, 接近0.05显著阈值)。

这说明什么？

- **高健康意识者的信任效应被削弱:**
  - HC低(-1SD)时: Trust对Intention的效应 = 0.282 + (-0.181)×(-1.010) = 0.465 (强)
  - HC高(+1SD)时: Trust对Intention的效应 = 0.282 + (-0.181)×(+1.010) = 0.099 (弱)

- **心理学解释:**
  - 高健康意识的人可能更"理性"。他们不会盲目信任建议来源，而是进行批判性评估。
  - "AI很有信息量，但我需要根据自己的健康知识判断这是否适用于我的情况。"
  - 相比之下，低健康意识者更依赖于**启发式线索(heuristic cues)**，如"这来自可信的来源"。

- **自我效能感的调节不显著(SE×HC p=0.480)**，说明HC对SE→Intention的削弱作用没有达到统计显著水平。这可能因为SE(自我效能)本身已经是行为的强预测因子，HC的额外调节空间有限。

---

#### 【a路径调节】源头效应的HC差异

**模型C2A和C2B结果(a路径调节):**

| 交互项 | IV→Trust系数 | IV→SE系数 | 两者p值 |
|--------|------------|----------|--------|
| Source×HC | 0.052 (ns) | 0.028 (ns) | 都不显著 |
| Frame×HC | -0.307 (ns) | 0.281 (ns) | 都不显著 |
| Interaction×HC | -0.468 (ns) | -0.417 (ns) | 都不显著 |

**关键发现:**
- **Source和Frame对Trust/SE的影响不随HC水平变化**(所有交互项p>0.4)
- 换句话说：**无论你的健康意识水平如何，AI的信任增强效应是一致的**

**解释:**
- 这说明**来源效应(Source Effect)和框架效应(Frame Effect)是相对稳定的基础效应**
- 不管你健康意识高还是低，你都会受到"AI vs 人类"和"损失 vs 收益"信息的影响
- 但**如何将这些信任与效能感转化为行为意图**(b路径)才是HC发挥调节作用的地方

## 条件间接效应分析：HC水平如何改变整体效应

### 核心数据对照

|  | HC低(-1SD) | HC中(Mean) | HC高(+1SD) | 趋势 |
|---|----------|----------|----------|------|
| **Source间接效应** | 0.247 | 0.183 | 0.105 | ↓递减 |
| **Frame间接效应** | -0.104 | -0.167 | -0.069 | 非单调 |
| **交互间接效应** | 0.594 | 0.231 | -0.028 | ↓急剧递减 |

### 逐项解读

#### 1. **Source(AI优势)的间接效应随HC递减**

```
HC低:  AI → Trust (+0.25) → 意图
       这里AI建议的信任优势**完全发挥**
       
HC高:  AI → Trust (+0.25) → 意图  (但Trust效应↓)
       高意识人群对来源的信任依赖更低
       即使信任AI，也不会无条件采纳
```

**管理启示:** 
向**高健康意识人群**推销AI健康建议时，"这来自AI"这个标签**效果递减**。需要更多的**证据、数据、个性化推荐**来说服他们，而非仅仅声称AI的权威性。

---

#### 2. **Frame(损失框架)的间接效应呈非单调关系**

```
HC低:  -0.104   (损失框架略微削弱意图)
HC中:  -0.167   (损失框架显著削弱意图,最强)
HC高:  -0.069   (损失框架削弱效应减弱)
```

**有趣的反转:**
- **中等健康意识** 对损失框架**最敏感**(效应最强-0.167)
- **低和高健康意识** 对损失框架**相对钝感**

**解释这个U形曲线:**
- **HC低:** 低意识人群可能不太理解"不运动的坏处"这类抽象消息，信息处理浅层，损失框架效应有限
- **HC中:** 中等意识人群"刚好"能理解这类消息，并产生适度焦虑，最有效削弱行为意图
- **HC高:** 高意识人群**过度理解**这类消息，他们可能因对自己的健康监测能力有信心而不怕这些"坏后果"，反而表现出抗性

**实践意义:**
不能假设"损失框架对所有人都有效"。需要根据目标群体的健康意识水平**差异化设计信息框架**。

---

#### 3. **交互效应(AI×损失)显示HC最强的调节**

```
HC低:  +0.594   (AI消息+损失框架协同增强意图!)
HC中:  +0.231   (协同效应减弱)
HC高:  -0.028   (协同效应几乎消失)
```

**最重要的发现:**

当健康意识**最低**时，**AI+损失框架的组合**产生**最强的正向协同效应**(+0.594)。

这反映了什么心理学过程？
```
低HC人群的认知过程:
  AI说 + "你不运动就生病" → "哇，权威的、科学的警告!" 
  → 焦虑感上升但不到无助程度 
  → "我应该听从这个聪明的AI" 
  → 行为意图提升至最高

高HC人群的认知过程:
  AI说 + "你不运动就生病" → "我已经知道这些了"
  → "但我的运动方式需要符合我自己的健康计划"  
  → AI和损失框架的'催促'对我没有额外说服力
  → 协同效应消失甚至反向
```

## 整体模型对比与拟合改进

### 模型演进路径

| 模型 | R² | 改进 | 统计显著性 | 解释 |
|--|--|--|--|--|
| Model 1 (总直接) | 0.103 | — | p=0.169 | 直接效应微弱 |
| Model 3 (基准中介) | 0.439 | +327% | **p<0.001*** | 中介机制显著 |
| Model C1 (b调节) | 0.522 | +19.0% | **p<0.001*** | HC调节中介效能显著 |
| Model C-Full (全调节) | 0.481 | +9.7% | p=0.002** | 完整调节机制 |

**R²改进与解释:**

1. **Model 3的+327%改进最关键:** 说明这个数据**根本性地支持中介机制**。Source和Frame的效应**几乎完全通过心理中介**(信任、效能感)发挥作用。

2. **Model C1的+19.0%额外改进:** HC调节效应显著。加入HC及其与中介变量的交互后，模型解释力进一步提升，说明HC确实以**缓冲/调节**的角色存在。

3. **Model C-Full相对改进幅度较小(9.7%):** a路径调节(IV→Mediator)的贡献有限。这与我们的发现一致：**Source和Frame对中介的影响是稳定的(independent of HC)**，而HC主要在**b路径**(中介→结果)发挥调节作用。

## 关键发现总结

### 发现1: AI信息来源的Trust优势是稳定的，不受HC影响
- **Source → Trust: 0.773**, p=0.044, **不因HC调节而改变**(Source×HC=0.052, ns)
- 无论用户的健康意识水平如何，**"AI提供的建议"这个标签都能增加被视为值得信任的程度**
- 但这种信任转化为行为意图的效率**会被HC削弱**(Trust×HC=-0.181, p=0.117)

### 发现2: 损失框架的效应存在"甜蜜点"
- 整体上损失框架略显负向，但**效应大小严重依赖于HC水平**
- **HC中等人群** 对"不运动的坏处"**最敏感**(-0.167)
- 暗示需要**分众化设计**: 对低意识人群用更直白的损失消息，对高意识人群用更多的科学性细节

### 发现3: AI×损失框架的协同效应在HC低时最强
- **HC低时: +0.594** (强正向协同)
- **HC高时: -0.028** (协同几乎消失)
- 这提示: 对低健康意识人群，**综合信息源权威性(AI) + 紧迫性感知(损失框架)**效果最佳
- 但这种"推动力"对高意识人群**完全失效**

### 发现4: 自我效能感的调节作用边界有限
- **SE → Intention: 0.437**, p=0.001 (最强的中介效应)
- 但 **SE×HC = 0.082**, ns (HC对SE→Intention的调节不显著)
- 说明: 自我效能感本身**高度预测行为意图**，超越了健康意识的调节范围

## 理论与实践意图

### 理论层面

1. **来源效应(Source Effect)的稳定性:** 无论目标受众的背景如何(高低健康意识)，信息来源(AI vs 人类)的可信度评价相对稳定。这支持了**启发式系统1思维**(自动、快速)对来源属性的处理。

2. **框架效应(Frame Effect)的调节机制:** 损失框架的说服力**不是固定的**，而是**与个体认知特征(健康意识)互动**。高意识个体在进行更深层的系统2思考，而低意识个体更依赖启发式。

3. **调节中介(Moderated Mediation)的证实:** Health Consciousness主要在**b路径**(中介→结果)而非a路径(源→中介)上发挥调节作用。这说明**起点相同(都产生了信任和效能感)，但终点不同**(高意识者更难将这些转化为行为)。

### 实践应用

#### 针对低健康意识人群:
✓ 优先使用AI来源标签  
✓ 配合损失框架("不运动的风险")  
✓ 强调AI的科学性和权威性  
✗ 避免过度技术细节  

**预期效果:** 信任↑ + 效能感↑ + 意图↑

#### 针对中健康意识人群:
✓ 损失框架效果最强，充分利用  
✓ 提供对标他人的社会对比信息  
✓ 结合AI推荐的个性化运动方案  

**预期效果:** 框架效应最大化

#### 针对高健康意识人群:
✓ AI来源不是主要说服点  
✓ 转向证据、研究数据、ROI  
✓ 强调自主性和个人化定制  
✗ 不要"吓唬"他们  

**预期效果:** 理性说服 > 情感推动

## 统计学注记

**样本量考虑:**
- n=50虽然满足基本的10:1规则(预测变量:样本)，但**小样本可能过度拟合**
- Trust×HC边界显著(p=0.117)，更大样本可能确认统计显著
- **建议:**对结果的解释采用"趋势性发现"而非"确定性结论"

**多重比较:**
- 进行了多个交互项和间接效应检验
- 未进行Bonferroni修正(保守但可能过度纠正)
- 现在的p值应视为**描述性而非确定性**的

**中心化与交互：**
- 连续变量(HC)进行了中心化，便于解释交互项系数
- 二元变量(Source, Frame)保持原始0/1编码，便于保持解释的直观性

## 结论

这项调节中介分析揭示了一个**动态的说服过程**，其中**信息来源(Source)、信息框架(Frame)和个体特征(Health Consciousness)通过三层机制互动**:

1. **第一层(a路径):** 来源和框架影响信任和效能感 — **这个过程对各类受众相对稳定**
2. **第二层(b路径):** 中介变量影响行为意图 — **这个过程因HC而异**
3. **第三层(调节):** 健康意识缓冲或放大了中介效应 — **高意识者更理性，低意识者更易受启发**

**最核心的洞察:** 在健康传播中，**不存在万能的说服策略**。同一条信息(无论AI或人类来源、无论损失或收益框架)对不同健康意识水平的人群会产生**完全不同的心理反应和行为结果**。未来的AI健康教练应该具备**自适应能力**，根据用户的健康知识和意识水平**动态调整信息策略**。
