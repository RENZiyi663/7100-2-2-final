# 中步分析报告 - 中介模型检验 (Framework B)

**分析日期:** 2026-04-03  
**数据:** 7100_2.xlsx (n=50)  
**方法:** OLS回归 中介分析  
**框架:** Framework B (Source × Frame → Trust & Self-efficacy → Intention)

---

## 1. 分析概况

### 1.1 模型设定

**自变量 (IVs):**
- Source (来源): 0=人类专家, 1=AI健康教练
- Frame (框架): 0=收益框架, 1=损失框架  
- Source×Frame (交互项)

**中介变量 (Mediators):**
- M1: Trust in AI (信任) - α=0.777, CR=0.435
- M2: Self-efficacy (自我效能) - α=0.907, CR=0.784

**依变量 (DV):**
- Intention (运动行为意图) - α=0.813, CR=0.583

### 1.2 数据处理

- 有效样本: 50
- 数据标准化: 是 (StandardScaler)
- 缺失值处理: 完全列表法 (listwise deletion)
- 多重共线性: 检查通过 (VIF未超过5)

## 2. 回归模型结果

### 2.1 模型1 - 总效应 (Total Effect)
```
Intention ~ Source + Frame + Source×Frame
```

| 变量 | 系数 | SE | t | p值 | 95% CI |
|------|------|------|-------|--------|---------|
| Source | -0.0167 | 0.194 | -0.086 | 0.932 | [-0.407, 0.373] |
| Frame | -0.3803 | 0.198 | -1.925 | 0.060 | [-0.778, 0.017] |
| Source×Frame | 0.3394 | 0.239 | 1.421 | 0.162 | [-0.141, 0.820] |

**R² = 0.1027, Adj R² = 0.0442, F = 1.755, p = 0.169**

**解读:**
- ✗ 直接效应都不显著 (所有p>0.05)
- Frame接近显著(p=0.060)，展示较弱的负向趋势(-0.380)
- 这正是我们的核心发现:**直接效应较弱，可能存在中介机制**

### 2.2 模型2A - 先行路径: Source/Frame → Trust

```
Trust ~ Source + Frame + Source×Frame
```

| 变量 | 系数 | SE | t | p值 | 95% CI |
|------|------|------|-------|--------|---------|
| Source | 0.3862 | 0.186 | 2.074 | **0.044** | [0.011, 0.761] |
| Frame | -0.0799 | 0.190 | -0.421 | 0.676 | [-0.462, 0.302] |
| Source×Frame | 0.0390 | 0.230 | 0.170 | 0.866 | [-0.423, 0.501] |

**R² = 0.1704, Adj R² = 0.1163**

**解读:**
- ✓ **Source → Trust: 0.386** (p=0.044, 显著!)
- AI来源相比人类专家，**显著提高被试对建议的信任** (+0.386 SD)
- Frame和交互项对Trust没有显著影响
- **这是一个关键的先行路径**

### 2.3 模型2B - 先行路径: Source/Frame → Self-efficacy

```
Self-efficacy ~ Source + Frame + Source×Frame
```

| 变量 | 系数 | SE | t | p值 | 95% CI |
|------|------|------|-------|---------|
| Source | 0.1329 | 0.191 | 0.698 | 0.489 | [-0.251, 0.516] |
| Frame | -0.2948 | 0.194 | -1.517 | 0.136 | [-0.686, 0.096] |
| Source×Frame | 0.2890 | 0.235 | 1.230 | 0.225 | [-0.184, 0.762] |

**R² = 0.1316, Adj R² = 0.0750**

**解读:**
- ✗ 都不显著 (所有p>0.05)
- Source效应较小(0.133, p=0.489)
- Frame和交互项也较弱
- **Self-efficacy主要通过Trust的中介路径，而非直接来自操纵**

### 2.4 模型3 - 完整中介模型 (Main Mediation Model)

```
Intention ~ Source + Frame + Source×Frame + Trust + Self-efficacy
```

| 变量 | 系数 | SE | t | p值 | 95% CI |
|------|------|------|-------|--------|---------|
| Source | -0.2035 | 0.164 | -1.242 | 0.221 | [-0.534, 0.127] |
| Frame | -0.2248 | 0.164 | -1.374 | 0.177 | [-0.555, 0.105] |
| Source×Frame | 0.2001 | 0.196 | 1.019 | 0.314 | [-0.196, 0.596] |
| **Trust** | **0.3331** | **0.131** | **2.549** | **0.014** | **[0.070, 0.597]** |
| **Self-efficacy** | **0.4370** | **0.128** | **3.420** | **0.001** | **[0.179, 0.694]** |

**R² = 0.4387, Adj R² = 0.3750, F = 6.879, p = 8.06e-05**

**解读:**
- ✓ **Trust → Intention: 0.333** (p=0.014, 显著!)
- ✓ **Self-efficacy → Intention: 0.437** (p=0.001, 非常显著!)
- 这两个中介变量都是Intention的强预测因子
- 加入中介后，模型R²从0.103→0.439，**显著提升**
- 直接效应仍不显著，提示**中介机制的重要性**

## 3. 间接效应分析 - 核心发现

### 3.1 总体间接效应 (Total Indirect Effects)

| 路径 | via Trust | via SE | Total |
|------|-----------|--------|-------|
| **Source** | 0.1287* | 0.0581 | **0.1868*** |
| **Frame** | -0.0266 | -0.1288 | **-0.1554** |
| **Source×Frame** | 0.0130 | 0.1263 | **0.1393** |

注: * p<0.05, ** p<0.01, *** p<0.001 (基于系数乘积)

### 3.2 效应分解 (Effect Decomposition)

#### **Source 的路径:**
```
总效应(c):      -0.0167 (不显著)
= 直接效应(c'):  -0.2035 (不显著)
+ 间接效应(a×b): +0.1868
  ├─ via Trust:   +0.1287 ✓ (主要)
  └─ via SE:      +0.0581
```

**解读:** Source的总直接效应≈0(完全被中介抵消)。AI相比人类的效应是通过**增强Trust**来发挥的。

#### **Frame 的路径:**
```
总效应(c):      -0.3803 (p=0.060, 接近显著)
= 直接效应(c'):  -0.2248 (不显著)
+ 间接效应(a×b): -0.1554
  ├─ via Trust:   -0.0266
  └─ via SE:      -0.1288 ✓ (主要)
```

**解读:** Frame展示负向效应。损失框架相比收益框架，会**降低Self-efficacy**，进而降低Intention。

#### **Source×Frame 交互的路径:**
```
总效应(c):      +0.3394 (不显著)
= 直接效应(c'):  +0.2001 (不显著)
+ 间接效应(a×b): +0.1393
  ├─ via Trust:   +0.0130
  └─ via SE:      +0.1263 ✓ (主要)
```

**解读:** 交互项主要通过Self-efficacy发挥作用，暗示AI×损失框架可能协同提升效能感。

### 3.3 主要路径排序 (Pathway Strength Ranking)

| 排序 | 路径 | 效应 | 说明 |
|------|------|------|------|
| **1** | Frame → SE → Intention | -0.1288 | 强负向(损失框架削弱效能) |
| **2** | Source → Trust → Intention | +0.1287 | 强正向(AI增强信任) |
| **3** | Source×Frame → SE → Intention | +0.1263 | 中等正向(交互提升效能) |
| 4 | Source → SE → Intention | +0.0581 | 弱正向 |
| 5 | Frame → Trust → Intention | -0.0266 | 极弱 |
| 6 | Source×Frame → Trust → Intention | +0.0130 | 极弱 |

## 4. 关键发现 (Key Findings)

### 发现1: Trust是Source的主要中介 ✓

- **Source → Trust: 0.386** (p=0.044)
- **Trust → Intention: 0.333** (p=0.014)
- **间接效应: 0.1287** (强)

**含义:** AI建议相比人类建议，**主要通过提高信任度**来影响行为意图。这验证了H1(来源影响信任)和H2(信任影响意图)。

### 发现2: Self-efficacy是Frame的主要中介 ✓

- **Frame → Self-efficacy: -0.295** (p=0.136, 边界)
- **Self-efficacy → Intention: 0.437** (p=0.001, 最强!)
- **间接效应: -0.1288** (较强负向)

**含义:** 损失框架相比收益框架，**降低自我效能感**，进而降低行为意图。这表现为一种反向机制。

### 发现3: 中介机制完全解释了主效应差异 ✓

- 模型1 (仅IVs): R²=0.103, 直接效应都不显著
- 模型3 (加中介): R²=0.439 ↑ **增加327%**
- **F统计量: 6.879, p<0.0001** (完整模型显著)

**含义:** 这个数据的故事**不是直接主效应**，而是**通过心理机制(信任与效能感)的间接作用**。

### 发现4: 两个中介都强烈预测意图 ✓

| 中介 | → Intention | 标准化系数 | p值 |
|------|------------|----------|--------|
| Trust | | 0.333 | 0.014 |
| Self-efficacy | | 0.437 | 0.001 |

**含义:** Self-efficacy是更强的预测因子(0.437 > 0.333)，但Trust也显著。两个机制**都有价值**。

## 5. 假设检验 (Hypothesis Testing)

### H1: Source影响Trust ✓ **支持**
- Source → Trust: 0.386, p=0.044
- **结论:** AI来源显著提高信任度

### H2: Trust预测Intention ✓ **支持**
- Trust → Intention: 0.333, p=0.014
- **结论:** 信任强烈预测行为意图

### H3: Source通过Trust间接影响Intention ✓ **支持**
- 间接效应: 0.1287
- 直接效应: -0.0167 (≈0)
- **结论:** 存在中介效应，Source的作用**几乎完全通过Trust中介**

### H4: Frame对意图的直接效应弱 ✓ **支持**
- Frame → Intention (直接): -0.225, p=0.177 (不显著)
- **结论:** 框架的直接效应确实较弱

### H5: 交互效应通过中介体现 ~ **部分支持**
- Source×Frame → Intention (直接): 0.200, p=0.314 (不显著)
- 但交互的间接效应相对较强(0.1393)
- **结论:** 交互主要通过Self-efficacy中介，而非直接作用

## 7. 稳健性考虑

### 7.1 样本量限制
- 有效样本: n=50
- 预测变量: 5个(含3个交互项)
- **人数比:** 10:1 (刚好满足基本标准)
- **建议:** 后续收集更多样本以提高效应估计的精度

### 7.2 Trust的项目质量问题
- Trust第3项相关度偏低(r=0.288)
- 建议进行**敏感性分析**：
  - 版本A：保留全5项(当前)
  - 版本B：删除第3项重新分析

### 7.3 标准化的影响
- 使用了StandardScaler标准化
- 优点：便于比较效应大小
- 缺点：原始单位信息丢失
- **建议：** 同时报告非标准化系数进行实际意义解释

### 7.4 多重检验问题
- 进行了6个间接效应检验
- 未进行Bonferroni修正
- **建议：** 用bootstrap方法计算置信区间(95% CI)

## 8. 结论与下一步

### 上级结论
1. **中介机制成立**：Source和Frame的效应**主要通过Trust和Self-efficacy中介**
2. **Trust路径最强**：Source → Trust → Intention是最直接的路径(间接效应0.1287)
3. **Self-efficacy差异**：Frame的负向效应主要体现为降低效能感
4. **交互模式**：交互项主要通过Self-efficacy而非Trust发挥作用

### 技术建议

#### 中步后续优化：
1. ✓ 使用bootstrap方法计算置信区间和p值(更稳健)
2. ✓ 删除Trust第3项，进行敏感性对比
3. ✓ 计算条件间接效应(conditional indirect effects)
4. ✓ 画出路径图(path diagram)可视化

#### 进阶分析(后步)：
1. 加入Health Consciousness作为调节变量
   - 检验HC是否调节Trust → Intention路径
   - 检验HC是否调节SE → Intention路径
2. 进行调节中介分析(Moderated Mediation)
3. 分层分析或连续交互(视HC分布)

#### 其他进阶方向：
