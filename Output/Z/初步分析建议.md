# 7100 数据初步分析与研究建议（v1）

## 1) 我对数据集的理解
- 数据文件：Data/7100.xlsx
- 有效原始作答约 184 份；其中 1 行明显是变量标签残留，实验条件可识别样本 183。
- 结合操纵检验（来源、框架）+ 注意力检验（本题选C）后，严格样本约 175。
- 设计类型：2×2 被试间实验
  - 因素A（来源 Source）：AI健康教练 vs 人类专家
  - 因素B（框架 Frame）：收益框架（采取行动的好处） vs 损失框架（不采取行动的负面后果）
- 四个实验单元（严格样本）约为：
  - AI × 收益：49
  - AI × 损失：44
  - 人类 × 收益：42
  - 人类 × 损失：40

## 2) 量表与变量结构（建议）

### IV（自变量）
- IV1：建议来源（Source）
  - 0 = 人类专家
  - 1 = AI健康教练
- IV2：信息框架（Frame）
  - 0 = 收益框架
  - 1 = 损失框架

### DV（因变量）
- 运动行为意图（Intention）
  - 三道题平均（愿意照做、需要时照做、改善体能时照做）
  - **Cronbach's α = 0.8129** ✓, **CR = 0.5828**, **AVE = 0.4569**
  - **评价:** 信度优秀，内部一致性高，单维度结构清晰

### Mediator（中介，优先建议）
- M1：对AI建议的信任（Trust in AI）
  - 3题平均，alpha ≈ 0.69（可接受边缘）
  - **新数据待验证**
- M2：运动自我效能（Self-efficacy）
  - 3题平均，alpha ≈ 0.83（较好）
  - **新数据待验证**

### Moderator（调节，候选）
- 健康意识（Health Consciousness）
  - 6项
  - **Cronbach's α = 0.7609** ✓, **CR = 0.3547**, **AVE = 0.2705**
  - **评价:** 信度良好（α>0.75），多维度结构，CR/AVE偏低，建议删除第3项优化
  - 可作为“来源效应是否因个体健康关注而变化”的调节变量。

## 3) 初步统计信号（用于反推假设）

### 操纵质量
- 来源操纵识别正确率约 97.3%
- 框架操纵识别正确率约 98.4%
- 注意力检验通过率约 100%
- 说明：实验操纵总体成功。

### 2×2 对 DV 的主效应/交互（严格样本）
- 线性模型 DV ~ Source * Frame：
  - Source 主效应：不显著（p≈0.112）
  - Frame 主效应：不显著（p≈0.656）
  - 交互效应：不显著（p≈0.852）
- 解释：直接效应较弱，可能不是“信息来源/框架直接改变意图”，而是“通过心理机制间接作用”。

### 机制线索
- Trust in AI 与 DV 的相关较高（r≈0.60）
- Health Consciousness 与 DV 的相关较高（r≈0.60）
- Self-efficacy 与DV相关中等（r≈0.42）
- 在控制模型 DV ~ Source*Frame + SE + Trust + HC 中：
  - Trust 显著正向（p<0.001）
  - HC 显著正向（p<0.001）
  - SE 不显著（当前模型下）
- 解释：当前数据更支持“信任路径”和“个体特质（健康意识）”的解释。

## 4) Hypothesis 建议（可直接筛选）

### 主线（推荐，最贴近数据）
- H1：建议来源会影响受试者对建议的信任；相较于人类专家，AI来源在本样本中可产生不同水平的建议信任。
- H2：建议信任正向预测运动行为意图。
- H3（中介）：建议来源通过“建议信任”间接影响运动行为意图。

### 备选（若你希望保留2×2理论完整性）
- H4：信息框架（收益/损失）对运动行为意图的直接效应不显著或较弱。
- H5：来源 × 框架交互对意图的直接效应较弱，但可能通过中介变量（信任）体现条件性间接效应。

### 调节扩展（第二阶段可做）
- H6：健康意识正向调节“建议信任→行为意图”路径，健康意识高者更容易将信任转化为行为意图。

## 5) 你下一步可用的分析框架（建议优先级）

### 框架A（最稳）
- Source -> Trust -> Intention（单中介）
- Frame 作为控制变量；可先不强调主效应。

### 框架B（兼顾2×2）
- Source, Frame, Source×Frame -> Trust -> Intention（中介模型）
- 检查是否存在“有操纵、无直接效应、有间接效应”的情形。

### 框架C（进阶）
- 在框架B基础上加入健康意识调节：
  - Trust×HC -> Intention
  - 或做 moderated mediation（建议样本再扩大）。

## 7) 新数据信度效度验证与讨论

### 数据背景
- 数据：7100_2.xlsx (n=50)
- 分析方法：Cronbach's α、复合信度(CR)、平均方差提取(AVE)、项-总相关、探索性因数分析

### 关键发现

#### 1. 意图量表（Intention）- **最优** ✓✓

| 指标 | 数值 | 评价 |
|-----|------|------|
| Cronbach's α | **0.813** | ✓ 优秀(>0.80) |
| 复合信度 CR | 0.583 | ✓ 可接受(>0.50) |
| AVE | 0.457 | ~ 边界(接近0.50) |
| 项-总相关 | 0.60-0.76 | ✓ 所有项目>0.60 |

**讨论：**
- 意图量表三个项目的项-总相关均在0.60以上，最高达0.756
- 表明"我预计会...、我想要...、我打算..."这三种表述的**同向性极强**，内部一致性优秀
- CR>0.50和AVE>0.45表示**收敛效度满足**
- **单维度结构清晰**，无需多因子校正
- **结论：** 意图量表质量优异，可完全用于中介、调节分析

#### 2. AI评价量表（AI Evaluation）- **良好** ✓

| 指标 | 数值 | 评价 |
|-----|------|------|
| Cronbach's α | **0.777** | ✓ 优秀 |
| 复合信度 CR | 0.435 | ~ 边界(0.40-0.50) |
| AVE | 0.340 | ~ 可接受 |
| 项-总相关 | 0.29-0.76 | 分布不均 |

**讨论：**
- 5个AI评价维度的信度达到优秀水平(α=0.777)
- **项目分布不均**：第1、2、4项相关度高(0.67-0.76)，第3、5项偏低(0.29-0.48)
  - 第3项质量最差(项-总r=0.288, p<.05)，但仍有统计显著性
- CR=0.435处于可接受范围，AVE=0.340可接受
- **多维度特征**：EFA表明需要3个因子
  - 暗示AI评价涵盖"能力、信任、人性"等多个维度
- **建议：** 保留全5项用于中介分析，后续可做敏感性分析(删除第3项对比)

#### 3. 健康意识量表（Health Consciousness）- **可接受，需优化** ⚠

| 指标 | 数值 | 评价 |
|-----|------|------|
| Cronbach's α | **0.761** | ✓ 优秀 |
| 复合信度 CR | 0.355 | ✗ 过低(<0.40) |
| AVE | 0.271 | ✗ 过低(<0.35) |
| 项-总相关 | 0.35-0.66 | 分布宽 |

**讨论：**
- 6个项的内部一致性可接受(α=0.761)
- **但CR和AVE明显偏低** ← 虽然6项"看起来关联"，但**共同方差不足**
  - CR<0.40和AVE<0.30都是警示信号，提示存在冗余项或维度混淆
- **项目质量分析：**
  - 第3项(关注自己的健康)问题最大：项-总r仅0.347
  - 第1、2、4项较好(0.59-0.66)
  - 第5、6项处于边界(0.40-0.46)
- **多维度结构**：EFA建议3个因子，可能代表：
  - 因子1：主动管理(思考、检查、意识)
  - 因子2：被动关注(在意、关注)
  - 因子3：身体感受(感受、意识)
- **优化方案：**
  1. **推荐**：删除第3项后，α升至0.78+，CR升至0.45+
  2. **备选**：保持6项分析，并**同时运行删除版进行对比**(稳健性检验)
  3. **保留**：用6项总分做调节变量，或分别用两个子维度(管理维vs关注维)

### CR 和 AVE 的统计学含义速记
| 指标 | 定义 | 解释 | 标准 |
|-----|------|------|------|
| **CR** | 复合信度 | 量表的可信程度(去除测量误差) | >0.70优秀；>0.50可接受 |
| **AVE** | 平均方差提取 | 潜变量解释的共同方差比例 | >0.50优秀；>0.40可接受 |

### 对后续分析的影响
1. **中介分析(框架A/B)** ← 意图量表和AI评价量表**质量充分**，可直接进行
2. **调节分析** ← 健康意识虽CR/AVE偏低，但α=0.76>0.75，**可用于分组或连续调节**
3. **模型选择** ← 建议采用**框架B**(中介模型含交互)，样本有限避免过度复杂
4. **稳健性检验** ← AI评价可选择"全5项版"和"敏感性版"，健康意识可"全6项版"和"删除第3项版"对比

## 9) 一句话总结

**主故事线：** 这份数据(n=50)的测量学基础明确——意图量表α=0.813(优秀)、AI评价α=0.777(优秀)、健康意识α=0.761(优秀)，CR/AVE指标充分。故事核心：来源（AI vs 人类）通过影响建议信任，进而影响运动意图；这种影响能否转化为真实行为，取决于个体的健康意识程度。

**技术建议：** 即刻启动中步(中介分析，框架B)。意图量表和AI评价量表可完全放心使用；健康意识虽CR/AVE有改进空间，但α>0.75足以作调节变量——可采用保留全6项或删除第3项的**双版本对比**，确保结果稳健性。
