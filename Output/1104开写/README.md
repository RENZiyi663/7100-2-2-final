## 📋 Quick Reference: Key Findings

### ✅ Supported Hypotheses
- **H7**: Health Consciousness moderates Source effect (β = -.39, p = .005)
- **Core Finding**: Attitude → Intention relationship (β = .69***)

### ❌ Unsupported Hypotheses
- **H1-H2**: No direct Source/Frame effects on Intention
- **H3-H6**: All indirect effects non-significant
- **Core Issue**: Cognitive-behavioral disconnection

### ⚡ Strongest Effects
1. Attitude → Intention: β = .69*** (explains 57% variance)
2. Source → Trust: β = -.50*** (strong but doesn't cascade)
3. Source → SE: β = -.30* (weak but significant)

### 📉 Zero/Weak Effects
- Trust → Intention: β = .03 ns
- All Frame effects: β = .02-.09 ns
- All indirect pathways: p > .05
