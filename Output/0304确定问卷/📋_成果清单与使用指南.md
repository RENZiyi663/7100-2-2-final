## 🎓 理论框架回顾

本分析采用**Moderated Mediation(调节的中介)**框架：

```
信息来源(Source) ──→ 信任(Trust) ──→ 行为意图(Intention)
   ↓
决策框架(Frame) ──→ 自我效能感(SE) ──→ 行为意图(Intention)
   
调节：健康意识(HC) 调节这两条中介路径的强度

模型特点：
✓ 解释IV如何通过中介变量(间接)影响DV
✓ 解释调节变量如何改变这些间接效应
✓ 可计算条件间接效应(按HC分层)
```
