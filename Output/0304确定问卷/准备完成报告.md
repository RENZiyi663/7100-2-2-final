## 🎯 下周数据输入准备

### 数据格式要求

- **文件位置:** `Data/7100_2.xlsx`
- **必需列数:** 62列(当前结构保持一致)
- **必需行数:** ≥50行(推荐100+行便于CFA/SEM)
- **数据类型转换:** CFA需要数值数据，文字会自动跳过
- **缺失值处理:** 完全列表删除法(listwise deletion)

### 关键列索引(如需修改)

| 变量 | 列号 | 备注 |
|------|------|------|
| Source | 29 | "刚刚这条健康建议来自于" |
| Frame | 30 | "这段健康建议强调的是" |
| Intention | 34-36 | 3项量表 |
| Self-Efficacy | 37-39 | 3项量表 |
| Trust in AI | 41-45 | 5项量表 |
| Health Consciousness | 46-51 | 6项量表 |

### 编码规则

```
Source: 
  "AI健康教练" → 1
  "人类专家" → 0
  
Frame:
  包含"负面"或"后果" → 1 (损失框架)
  其他 → 0 (收益框架)
```

如需修改，编辑 `comprehensive_analysis_framework.py` 中的 `AnalysisConfig` 和 `DataProcessor.encode_source_frame()`
