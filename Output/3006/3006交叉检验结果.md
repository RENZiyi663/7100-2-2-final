# 3006 新模型交叉检验结果

生成日期：2026-07-02  
目标：检验当前 `Data/R新模型/7100.csv` 是否能复现组员 SPSS 截图中的新模型结果，并判断新假设在不同编码/筛选口径下是否稳定。

---

## 1. 检验模型

本次交叉检验围绕同一个新模型展开：

```text
Intention ~ Source * Frame * HealthC_c
```

展开后包括 7 个预测项：

```text
Source
Frame
HealthC_c
Source × Frame
Source × HealthC_c
Frame × HealthC_c
Source × Frame × HealthC_c
```

因此，如果模型不加入额外控制变量，残差自由度与样本量关系为：

```text
N = df_error + 8
```

组员 SPSS 截图报告：

```text
F(7, 179) = 20.374
```

这意味着 SPSS 模型有效样本量约为：

```text
N = 179 + 8 = 187
```

而当前 CSV 原始样本量为：

```text
N = 199
```

---

## 2. 交叉检验口径

本次检验了五种口径：

| 口径 | 说明 |
|---|---|
| A | 使用 Stimuli 标签重建 clean Source / Frame，保留全部 199 个完整样本 |
| B | 使用原 CSV 中的 Source / Frame 数值列，但按已发现方向重定向为 AI=1、Gain=1 |
| C | 只保留原 Source/Frame 数值列与 Stimuli clean 编码一致的样本 |
| D | 只保留 `随机元素` 文本中没有重复/逗号标记的样本 |
| E | 同时满足“原数值编码与 clean 编码一致”且“随机元素无重复/逗号”的样本 |

## 3. 数据口径检查

| 指标 | 数值 | 说明 |
|---|---:|---|
| 原始 CSV 行数 | 199 | `Data/R新模型/7100.csv` 的总行数 |
| 主模型完整样本 | 199 | Source/Frame/Intention/HC 均完整 |
| 原数值编码与 Stimuli clean 编码一致 | 190 | 现有 Source/Frame 数值与 Stimuli 标签方向一致 |
| 原数值编码与 Stimuli clean 编码冲突 | 9 | 需要警惕的编码不一致样本 |
| `随机元素` 无重复/逗号文本 | 178 | 严格单一 Stimuli 标签样本 |
| `随机元素` 有重复/逗号文本 | 21 | 可能是系统记录重复或展示记录重复 |
| 同时满足 clean 匹配 + 单一 Stimuli | 171 | 最严格口径 |
| SPSS 截图暗示样本量 | 187 | 由 `df_error = 179` 推得 |

结论：当前能自然得到的样本量是 199、190、178 或 171，没有一个等于 SPSS 截图暗示的 187。因此，当前 CSV 的常见筛选口径不能解释组员截图的自由度。

## 5. 与 SPSS 截图的对照

组员截图核心结果大概为：

| Effect | SPSS 截图结果 |
|---|---:|
| Overall model | F(7,179)=20.374, R²/η²-like=.443 |
| HealthC | F=119.424, p<.001 |
| Source×HealthC | F=6.309, p=.013 |
| Frame×HealthC | F=11.061, p=.001 |
| Source×Frame×HealthC | F=8.164, p=.005 |

当前 CSV 交叉检验结论：

1. **整体 df 不匹配**：所有当前口径都无法得到 `df_error=179`。
2. **整体解释力接近但偏低**：当前模型 R² 约 `.389-.409`，SPSS 截图约 `.443`。
3. **HealthC 主效应稳定显著**，但当前 F 值远小于截图中的 `119.424`。
4. **Frame×HealthC 稳定显著**，这是最稳定复现的新模型交互项。
5. **Source×HealthC 不显著**，这与 SPSS 截图冲突最大。
6. **三重交互不稳定**：只有原数值编码重定向口径显著；clean 编码口径为边界显著，严格筛选后不显著。

## 6. 对四个新假设的稳定性判断

| Hypothesis | 内容 | 交叉检验判断 | 说明 |
|---|---|---|---|
| H1 | HealthC 正向预测 Intention | 稳定支持 | 五种口径均显著 |
| H2 | HealthC 调节 Source 效应 | 当前不支持 | 五种口径均不显著，与 SPSS 截图冲突 |
| H3 | HealthC 调节 Frame 效应 | 稳定支持 | 五种口径均显著，是最可靠交互结果 |
| H4 | HealthC 调节 Source×Frame 联合效应 | 不稳定/边界 | clean 全样本 p=.0596；原数值编码 p=.0437；严格口径不显著 |

因此，如果只依据当前 CSV 和 clean 编码，最稳妥的新模型假设结果是：

```text
H1 supported
H2 not supported
H3 supported
H4 marginal / not robust
```

## 7. 编码口径对结论的影响

### 7.1 clean 编码全样本

使用 Stimuli 标签重建：

```text
Stimuli A/B = AI
Stimuli C/D = Human
Stimuli A/C = Gain
Stimuli B/D = Loss
```

结果：

```text
N = 199
R² = .403
Frame×HealthC: p = .000150
Three-way: p = .0596
Source×HealthC: p = .5428
```

这是目前最推荐的主口径，因为它直接回到实验材料标签。

### 7.2 原数值编码重定向

使用 CSV 里的 Source / Frame 数值列，并按已发现方向重定向：

```text
Source: 0 appears AI, 1 appears Human，所以重定向为 AI=1
Frame: 1 appears Gain, 0 appears Loss
```

结果：

```text
N = 199
R² = .402
Frame×HealthC: p = .000112
Three-way: p = .0437
Source×HealthC: p = .5924
```

该口径让三重交互达到 p<.05，但 Source×HealthC 仍不显著，且仍无法解释 SPSS 的 df=179。

### 7.3 剔除编码冲突样本

剔除 9 个当前数值编码与 Stimuli 标签冲突的样本后：

```text
N = 190
R² = .409
Frame×HealthC: p = .000104
Three-way: p = .0550
Source×HealthC: p = .5614
```

三重交互仍是边界显著，不到 .05。

### 7.4 剔除重复 Stimuli 文本

只保留 `随机元素` 文本没有重复/逗号的样本：

```text
N = 178
R² = .389
Frame×HealthC: p = .001978
Three-way: p = .1187
Source×HealthC: p = .3125
```

这个口径让样本量更低，但仍不是 SPSS 的 187，而且三重交互不显著。

## 8. 核心结论

### 结论一：当前数据不能复现组员 SPSS 截图

当前 CSV 的可解释口径没有一个得到：

```text
df_error = 179
N ≈ 187
```

因此，组员 SPSS 截图很可能使用了：

1. 不同版本的数据文件；
2. 不同的缺失值处理；
3. 额外的筛选条件；
4. 不同的变量计算方式；
5. 或 SPSS 模型中纳入/排除了当前脚本没有处理的变量。

### 结论二：Frame×HealthC 是当前最稳的新模型发现

不论使用 clean 编码、原数值编码、剔除冲突样本，还是剔除重复 Stimuli 文本：

```text
Frame × HealthC 始终显著
```

这说明“健康意识改变 gain/loss frame 的作用”是当前数据里最可靠的交互结果。

### 结论三：Source×HealthC 不能在当前 CSV 中复现

所有当前口径下：

```text
Source × HealthC 均不显著
```

所以截图中的 `Source × HealthC: F=6.309, p=.013` 需要组员提供原始 SPSS 数据或筛选规则才能解释。

### 结论四：三重交互有趋势，但不够稳

三重交互在不同口径下表现为：

```text
clean 全样本：p = .0596
原数值编码：p = .0437
剔除编码冲突：p = .0550
单一 Stimuli：p = .1187
最严格口径：p = .0966
```

这说明三重交互存在一定趋势，但对编码/筛选口径敏感。正式论文中不宜在未复现 SPSS 口径前强写为稳定显著。

## 9. 建议给组员核对的问题

请组员确认以下信息：

1. SPSS 使用的具体数据文件是哪一个？是否就是 `Data/R新模型/7100.csv`？
2. SPSS 中有效样本为什么是约 187，而不是 199？
3. 是否使用 listwise deletion？哪些变量进入了 listwise deletion？
4. Source 和 Frame 是如何编码的？是否根据 Stimuli 标签重新编码？
5. HealthC_C 是 mean-centered 还是 z-standardized？
6. Intention 是否为三个题项平均值？是否排除了某些缺失或异常值？
7. 是否加入了 Sex、操纵检查、注意力检查或其他协变量？
8. 是否排除了 `随机元素` 重复记录、编码冲突样本、或操纵识别错误样本？

## 10. 当前最适合采用的结果表述

在组员没有提供 SPSS 筛选规则之前，建议采用如下保守表述：

> 基于 Stimuli 标签重建的 clean 编码模型显示，整体模型显著，健康意识显著正向预测运动行为意图，并显著调节信息框架对行为意图的影响。具体而言，Frame × Health Consciousness 交互在所有交叉检验口径中均保持显著，说明健康意识是解释收益/损失框架效果差异的关键边界条件。相比之下，Source × Health Consciousness 交互未能在当前 CSV 中复现，Source × Frame × Health Consciousness 三重交互仅呈边界显著且对编码/筛选口径敏感。因此，在确认 SPSS 的样本筛选与变量编码之前，不建议直接采用截图中的完整三重交互结论作为最终结果。
