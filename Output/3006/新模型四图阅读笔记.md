## 1. 这套“新模型”大概是什么

从四张图的文字看，组员这套结果不是当前 `Data/R新模型` 里的 SEM / lavaan 中介模型，而更像是一个以行为意图为因变量的 GLM / ANCOVA / moderation model：

- 自变量 1：Source，AI 教练 vs 人类专家
- 自变量 2：Frame，收益 vs 损失
- 调节变量 / 协变量：HealthC，健康意识，似乎做了中心化或连续变量处理
- 因变量：应为行为意图 / Intention
- 重点检验：Source x HealthC、Frame x HealthC、Source x Frame x HealthC

图片里称其为 ANCOVA，但因为报告了 `Source x HealthC`、`Frame x HealthC`、`Source x Frame x HealthC`，严格说它更像是包含连续调节变量交互项的 factorial ANCOVA / moderated regression / GLM，而不是只把 HealthC 当普通协变量的 ANCOVA。

## 2. 图 1426：结果概览表

图中给出的核心结果：

| Effect | F | p | partial eta squared | 图中结论 |
|---|---:|---:|---:|---|
| 整体模型 | F(7, 179) = 20.374 | < .001 | .443 | 模型成立，解释力强 |
| HealthC 主效应 | 119.424 | < .001 | .400 | 健康意识越强，意图越高 |
| Source x HealthC | 6.309 | .013 | .034 | 健康意识调节信源效应 |
| Frame x HealthC | 11.061 | .001 | .058 | 健康意识调节框架效应 |
| Source x Frame x HealthC | 8.164 | .005 | .044 | 三重交互显著 |
| Source 主效应 | 1.251 | .265 | -- | 不显著 |
| Frame 主效应 | .130 | .719 | -- | 不显著 |
| Source x Frame | .391 | .533 | -- | 不显著 |

这张图的核心信息是：

1. Source 和 Frame 本身没有主效应。
2. HealthC 主效应极强，是模型里最大的解释来源。
3. HealthC 不仅调节 Source，还调节 Frame。
4. Source、Frame、HealthC 的三重交互显著。

这和我们之前 R 新模型中 `10_H7_moderation_total.csv` 的方向有相似之处：也就是 Source 的总体效应确实可能受 HC 调节。但这套图进一步提出 Frame x HC 与 Source x Frame x HC 也显著。

## 3. 图 1427：HealthC 是“认知阀门”与 Source x HealthC

图中对 HealthC 的解释：

- `HealthC_C` 主效应极显著：F = 119.42, p < .001, partial eta squared = .400。
- 文字解释为：健康意识是预测行为意图最核心的因素。
- 健康意识越高，不管面对什么信源或框架，行为意图都更高。

Source x HealthC 的简单斜率 / simple effects：

| HealthC 水平 | Source 简单效应 |
|---|---|
| 低健康意识组 (-1 SD) | 人类专家 M = 5.61 显著优于 AI 教练 M = 5.36, p = .011 |
| 中等健康意识组 (mean) | 无显著差异, p = .265 |
| 高健康意识组 (+1 SD) | 无显著差异, p = .306；AI 均值甚至略高：6.29 vs 6.19，但未显著 |

图中解释为：AI 与人类专家的说服力差异，只存在于低健康意识人群；高健康意识者对“谁在说话”不敏感。

需要注意：这和我们用 Stimuli 标签反查得到的整体方向并不完全一致。我们之前检查发现，如果按 Stimuli 标签重建 `AI=1, human=0`，AI 组 Trust/SE 可能更高。但这里讨论的是 Intention 的条件均值，不是 Trust/SE；因此不一定直接冲突。不过 Source 编码仍必须核查。

## 4. 图 1428：Frame x HealthC 与三重交互

Frame x HealthC 结果：

- F = 11.06
- p = .001
- partial eta squared = .058

简单效应：

| HealthC 水平 | Frame 简单效应 |
|---|---|
| 低健康意识组 (-1 SD) | 收益框架 M = 5.61 显著优于损失框架 M = 5.36, p = .010 |
| 中等健康意识组 (mean) | 无显著差异, p = .719 |
| 高健康意识组 (+1 SD) | 方向完全逆转：损失框架 M = 6.34 显著优于收益框架 M = 6.14, p = .033 |

图中称这是 `Frame Reversal`，即健康意识低的人更吃收益框架，健康意识高的人反而更吃损失框架。

三重交互结果：

- Source x Frame x HealthC 显著：F = 8.16, p = .005, partial eta squared = .044。

图中给出的解释：

| 受众类型 | 信息加工路径 | 推荐策略 | 效果 |
|---|---|---|---|
| 低健康意识（小白） | 外围路径 | 人类专家 x 收益框架 | 显著有效 |
| 高健康意识（专家） | 中心路径 | AI x 损失框架，或人类 x 损失 | 显著有效 |

这个说法比较有叙事价值，但需要特别小心：它把统计交互直接解释成 ELM 的外围/中心路径，需要理论和数据同时支撑。若论文采用这套模型，Discussion 可以这么写；但 Results 里应先保持统计描述，不要直接过度心理机制化。

## 5. 图 1429：可直接使用的论文报告模板

图中给出一句话总结：

> 健康意识是健康信息说服的认知开关：低健康意识的人依赖信源与框架等外围线索，高健康意识的人则基于自身知识进行批判性加工——这不仅让信源优势消失，更让框架效应发生逆转。

图中给出的标准结果报告大意：

- 采用 2 Source x 2 Frame 被试间实验设计。
- 以 HealthC 为中心化协变量进行 ANCOVA。

- HealthC 主效应显著：F = 119.42, p < .001, partial eta squared = .400。
- Source 和 Frame 主效应均不显著。
- Source x HealthC 显著：F = 6.31, p = .013, partial eta squared = .034。
- Frame x HealthC 显著：F = 11.06, p = .001, partial eta squared = .058。
- 三重交互显著：F = 8.16, p = .005, partial eta squared = .044。

这个模板能用，但当前不建议直接粘贴到论文，原因见下方风险点。

## 6. 与当前 R 新模型的关系

这套 SPSS 图和我们已有 R 新模型并不是同一个模型。

当前 R 新模型重点是：

- measurement model / CFA
- SEM path model
- Source / Frame 对 Attitude、Trust、SE、Intention 的路径
- indirect effects
- H7 direct-effect moderation
- H7 total-effect moderation

SPSS 图重点是：

- Intention 作为单一因变量
- Source、Frame、HealthC 及其交互项
- 特别强调 Source x HealthC、Frame x HealthC、Source x Frame x HealthC

可以这样理解：

- R 新模型回答的是：Source / Frame 是否通过 Attitude、Trust、SE 影响 Intention？
- SPSS 新模型回答的是：Source / Frame 对 Intention 的作用是否取决于 HealthC？尤其是否存在二阶或三阶交互？

二者可以互补，但不能混为同一个模型。

## 7. 与已有数据结果的吻合点

吻合点：

1. Source 主效应不显著。
   - R 新模型中 Source -> Intention p = .7617。
   - SPSS 图中 Source 主效应 p = .265。

2. Frame 主效应不显著。
   - R 新模型中 Frame -> Intention p = .7300。
   - SPSS 图中 Frame 主效应 p = .719。

3. HealthC / HC 与 Intention 强相关。
   - R 新模型相关矩阵中 HC - Intention r = .564, p < .001。
   - SPSS 图中 HealthC 主效应 F = 119.42, p < .001, partial eta squared = .400。

4. Source x HealthC 的 total-effect 版本可能显著。
   - R 新模型 `10_H7_moderation_total.csv` 中 Source x HC p = .0047。
   - SPSS 图中 Source x HealthC p = .013。

## 8. 与已有结果的冲突或待核查点

### 8.1 样本量 / 自由度不一致

SPSS 图报告整体模型为：

- F(7, 179)

如果模型有 7 个预测自由度，残差 df = 179，则总 df 约为 186，样本量大约是 187。

但当前 R 新模型原始数据为：

- N = 199

这意味着 SPSS 可能：

- 使用了不同数据文件；
- listwise deletion 后只剩约 187；
- HealthC 或 Intention 某些变量有缺失；
- 或模型自由度/报告方式与普通回归不同。

必须问组员 SPSS 使用的原始文件、筛选规则、缺失值处理方式。

### 8.2 Source/Frame 编码仍需核查

我们已发现当前 `Data/R新模型/7100.csv` 中 Source/Frame 数值列与 Stimuli 标签存在少量不一致，而且 Source 方向可能与部分文字报告相反。

SPSS 图中的简单效应写法：

- 低 HealthC：人类专家 M = 5.61 > AI M = 5.36。
- 低 HealthC：收益框架 M = 5.61 > 损失框架 M = 5.36。
- 高 HealthC：损失框架 M = 6.34 > 收益框架 M = 6.14。

这些均值必须回到原始数据按 Stimuli 标签重算，不能只相信 SPSS 输出截图。

### 8.3 变量名 HealthC_C 说明它可能中心化过

图中写 `HealthC_C`，说明 HealthC 应该做了中心化。

需要确认：

- 是 mean-centering 还是 z-score？
- -1 SD / +1 SD 简单效应如何计算？
- Source/Frame 是否 effect coding、dummy coding，还是 SPSS GLM 因子编码？

这些会影响系数解释，但一般不改变 F 检验显著性。

### 8.4 “ANCOVA”术语可能不够精确

如果模型含有 Source x HealthC、Frame x HealthC、Source x Frame x HealthC，那么它不是最简单的 ANCOVA，而是带连续调节项的 factorial ANCOVA / moderation GLM。

论文中可写：

> A factorial ANCOVA / general linear model was conducted with Source and Frame as between-subject factors and mean-centered Health Consciousness as a continuous moderator.

比单纯写 ANCOVA 更准确。

## 9. 初步判断

这套 SPSS 新模型有潜力成为比当前 SEM 中介模型更适合论文主线的模型，原因是：

1. 结果更清晰：HealthC 是核心变量。
2. Source 和 Frame 主效应不显著，但交互显著，叙事上更合理。
3. 与 ELM / 信息加工路径理论更容易对接。
4. 能解释为什么总体主效应弱：因为效应只在特定 HealthC 水平出现，而且 Frame 效应会反转。

但它还不能直接作为最终结论，至少要先解决：

1. SPSS 实际使用的 N 为什么像是 187，而不是 199。
2. Source/Frame 编码方向是否基于 Stimuli 标签。
3. 简单效应均值是否能用原始数据复现。
4. 是否控制了 Sex 或其他变量。
5. HealthC_C 的处理方式。
6. Intention 的计算是否与 R 新模型一致。

## 10. 建议下一步

建议建立一个 clean-data 版本，用 Stimuli 标签重建实验条件，然后复现 SPSS 图中的 GLM：

模型可写为：

```text
Intention ~ Source_clean * Frame_clean * HC_c
```

可选控制变量：

```text
Intention ~ Source_clean * Frame_clean * HC_c + Sex
```

需要输出：

1. N 与缺失值处理说明。
2. Source_clean x Frame_clean 四格样本数。
3. Overall model F / R2。
4. HealthC 主效应。
5. Source 主效应、Frame 主效应、Source x Frame。
6. Source x HC。
7. Frame x HC。
8. Source x Frame x HC。
9. -1 SD、mean、+1 SD 的 simple effects。
10. 简单斜率图或 predicted means plot。

只有当这些结果能从 `Data/R新模型/7100.csv` 或组员的同一份 SPSS 数据中复现，才建议把这四张图作为论文最终模型依据。
