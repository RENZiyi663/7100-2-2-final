## 🔍 为什么FILE 2的显著性标记错了？

### 关键点

1. **虚假显著性**: FILE 2中标记了`*`的相关系数实际p值都 > 0.50
   - Source-Frame: p = 0.8049 ❌ 标为 `*`
   - Source-Attitude: p = 0.5755 ❌ 标为 `*`
   - Source-Intention: p = 0.9001 ❌ 标为 `*`

2. **丢失显著性**: FILE 2中没有标记星号的极显著关系
   - Trust-Intention: r = 0.37, p < 0.001 ❌ 应为 `***`

3. **可能原因**:
   - 自动导出或转录错误
   - 使用了不同的p值阈值标准
   - 显著性标记被错误地应用或合并

### 证据链

```
R新模型/03_correlation_pvalues.csv (官方数据)
    ↓
Source-Frame p-value = 0.8049 (ns)
    ↓
FILE 2中却标注为 0.02* ❌ (错误)
    ↓
本文件正确修正为 0.018ns ✓
```

## 📝 技术说明

### 多重比较校正
如果进行Bonferroni校正以控制Type I错误:
- 原始α = 0.05
- 比较次数 = 21 (7×6/2)
- 校正后α = 0.05/21 ≈ **0.0024**

在此校正下，许多p值在0.001-0.05范围内的相关系数会变为不显著。
