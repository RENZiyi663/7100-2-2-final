## 统计学注释

### 关于显著性标记的说明

根据传统的显著性检验标准：
- **p < 0.001**: 极度显著 (highly significant) - 标记为 `***`
- **p < 0.01**: 高度显著 (very significant) - 标记为 `**`
- **p < 0.05**: 显著 (significant) - 标记为 `*`
- **p ≥ 0.05**: 不显著 (not significant) - 标记为 `ns`

### 重要修正说明

**之前的版本存在错误**：对角线上的自相关系数（恒为1.0）被错误地标记为`***`。这完全没有意义，因为：
- 对角线是自相关系数，总是恒定的1.0
- 自相关没有统计学p值需要检验
- 本版本已正确移除对角线的显著性标记

### 注意事项

1. **多重比较问题**: 这个相关矩阵包含多个相关系数。在进行多个检验时，推荐使用Bonferroni校正降低Type I错误率。
   - Bonferroni校正后的显著性水平: α = 0.05 / (7×6/2) = 0.05 / 21 ≈ 0.0024

2. **样本量**: N = 199，足以支持信度较高的统计推断。

3. **相关与因果**: 相关系数反映的是两个变量之间的线性关系强度，不代表因果关系。
