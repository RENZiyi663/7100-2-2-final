## ⚠️ 常见错误处理

| 错误 | 原因 | 解决 |
|------|------|------|
| `Cannot open file` | 文件路径错 | `file.exists("~/Desktop/7100/7100.xlsx")` |
| `Package not found` | 包没安装 | `install.packages("lavaan")` |
| `Column index out of range` | 列号不对 | 检查Excel中列的对应关系 |
| `Model not converged` | 数据问题 | 检查是否有极端值或缺失 |
| `Object not found` | 变量名错 | 检查拼写(区分大小写) |

## 📈 结果解读速查表

### 模型拟合度判断标准

| 指标 | 优秀 | 可接受 | 不好 |
|------|------|--------|------|
| **CFI** | >0.95 | 0.90-0.95 | <0.90 |
| **RMSEA** | <0.05 | 0.05-0.10 | >0.10 |
| **SRMR** | <0.05 | 0.05-0.10 | >0.10 |

### 系数显著性判断

| p值范围 | 标记 | 解释 |
|---------|------|------|
| <0.001 | *** | 极显著(强烈证据) |
| <0.01 | ** | 显著 |
| <0.05 | * | 显著 |
| <0.10 | . | 边界显著(弱证据) |
| ≥0.10 | (无) | 不显著 |

### 效应大小参考(标准化系数)

| 范围 | 强度 |
|------|------|
| 0.00-0.10 | 极弱 |
| 0.10-0.20 | 弱 |
| 0.20-0.30 | 中等 |
| 0.30-0.40 | 强 |
| >0.40 | 极强 |

## 📞 紧急Q&A

**Q: 脚本跑了20分钟还没完？**
A: 正常。第1板块(包加载)会比较慢。其他板块都很快。

**Q: 能跳过某些板块吗？**
A: 可以。但建议从1-15都跑一遍。第1-3板块数据准备必须先做。

**Q: 数据和Python版本结果不一样？**
A: 检查excel中列号是否真的按照说明书对应，特别注意Header的skip=2。

**Q: 输出文件在哪？**
A: 
- PDF: `~/Desktop/7100/lavaan_path_diagram.pdf`
- TXT: `~/Desktop/7100/lavaan_analysis_results.txt`

**Q: 怎么改数据路径？**
A: 在脚本最上面找到这行：
```r
data_path <- path.expand("~/Desktop/7100/7100.xlsx")
```
改成你的实际路径。
